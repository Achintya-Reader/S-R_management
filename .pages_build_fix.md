# Pages build fix 2026-09-11

Error: `npx wrangler deploy` in Pages project -> `It looks like you've run a Workers-specific command in a Pages project. For Pages, please run wrangler pages deploy instead.`

Fix: Pages does NOT need `wrangler deploy`. Just publish static files + `functions/`.

In Cloudflare Dashboard > Pages > s-r-management > Settings > Builds & deployments
  Build command:  (leave empty)  or  `echo "no build"`
  Build output directory:  `.`
  Root directory:  (empty, since Deploy is repo root)
  Deploy command:  (none - Pages deploys automatically)

Do NOT set Deploy command to `npx wrangler deploy`. That is for Workers only.

Local test: `npx wrangler pages dev ./`  or  `npm run pages:dev`
Deploy via CLI: `npm run deploy:pages`
